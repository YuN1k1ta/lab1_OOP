\## Цель работы



Изучение принципов объектно-ориентированного программирования на языке C#, а также получение практических навыков создания классов, работы с объектами, конструкторами, методами, полями и свойствами.



В рамках работы необходимо разработать программу для работы с музыкальными треками и плейлистом, используя классы `Track` и `Playlist`.



\## Описание задания



Необходимо разработать консольное приложение на языке C#, моделирующее работу с музыкальными треками и плейлистом.



Каждый трек должен содержать информацию о своем номере, названии, исполнителе, длительности, количестве прослушиваний и жанрах.



Также необходимо реализовать класс `Playlist`, который позволяет хранить несколько треков и выполнять основные операции с ними: добавление, удаление, поиск наиболее популярного трека, подсчёт общей длительности и сортировку.



Программа должна обеспечивать корректность вводимых данных и не допускать выполнения недопустимых операций.



\## Постановка задачи



Необходимо реализовать:



\- класс `Track` для представления музыкального трека;

\- хранение номера трека;

\- хранение названия трека;

\- хранение исполнителя;

\- хранение длительности трека в секундах;

\- хранение количества прослушиваний;

\- ограничение длительности трека от 1 до 3600 секунд;

\- запрет создания трека с пустым названием;

\- возможность увеличения количества прослушиваний;

\- невозможность уменьшения количества прослушиваний;

\- статическое поле для подсчёта количества созданных объектов `Track`;

\- константу `MAX\_DURATION`, задающую максимальную длительность трека;

\- перегруженные методы `Play()` для увеличения количества прослушиваний;

\- работу с массивом жанров;

\- защиту внутреннего массива жанров от изменения извне;

\- класс `Playlist` для хранения и управления треками;

\- добавление трека в плейлист;

\- удаление трека по номеру;

\- подсчёт общей длительности всех треков;

\- поиск самого популярного трека;

\- сортировку треков по количеству прослушиваний.



\## Реализованные требования



\### Класс `Track`



Класс содержит данные о музыкальном треке:



\- номер;

\- название;

\- исполнитель;

\- длительность;

\- количество прослушиваний;

\- жанры.



Для создания объектов предусмотрены перегруженные конструкторы.



Реализована проверка корректности данных. Длительность трека не может быть меньше 1 секунды или больше значения `MAX\_DURATION` (3600 секунд). Название трека не может быть пустым.



\### Работа с прослушиваниями



Для увеличения количества прослушиваний реализованы перегруженные методы:



\- `Play()`;

\- `Play(int times)`.



Количество прослушиваний может только увеличиваться. Уменьшение количества прослушиваний не допускается.



\### Подсчёт объектов



В классе `Track` используется статическое поле, позволяющее подсчитывать количество созданных объектов данного класса.



Также определена константа:



MAX\_DURATION = 3600 которая задаёт максимально допустимую длительность трека.



\### Работа с жанрами



Для каждого трека предусмотрен массив жанров.



Для предотвращения изменения внутреннего массива извне используется защитное копирование. Получение жанров не позволяет напрямую изменить внутренние данные объекта `Track`.



\### Класс `Playlist`



Класс `Playlist` предназначен для хранения набора музыкальных треков.



В нём реализованы следующие операции:



\- добавление нового трека;

\- удаление трека по его номеру;

\- вычисление общей длительности всех треков;

\- поиск наиболее популярного трека;

\- сортировка треков по количеству прослушиваний.



\### Главное меню программы



В `Program.cs` реализовано консольное меню, с помощью которого пользователь может выбирать необходимое действие.



Пользователь может управлять треками и плейлистом непосредственно через консоль.



\### Обработка некорректных действий



Программа обрабатывает недопустимые операции, в том числе:



\- создание трека с длительностью `0`;

\- создание трека с пустым названием;

\- попытку уменьшить количество прослушиваний;

\- попытку удалить несуществующий трек;

\- ввод некорректных данных.



Таким образом, программа соответствует основным требованиям лабораторной работы по варианту 15.
